# Lumi v1.5.0 — Первый запуск

1. Распакуйте архив.
2. Запустите `scripts/START_LUMI_WINDOWS.bat` или `python run_lumi.py`.
3. Откройте dashboard: http://127.0.0.1:8000/ui
4. В панели «Безопасность» настройте пароль и разблокируйте систему.
5. В панели «Хранилище» проверьте профиль и сохранение состояния.
6. В панели «Провайдеры» создайте provider from preset, сохраните ключ через Secret Vault и выполните metadata-only test.

Ограничения: live calls отключены по умолчанию; нет реального применения патчей; нет фоновых вызовов; нет записи в host project.
