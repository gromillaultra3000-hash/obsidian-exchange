# Lumi v1.5.0 — First Run

1. Extract the archive.
2. Run `scripts/START_LUMI_WINDOWS.bat` or `python run_lumi.py`.
3. Open dashboard: http://127.0.0.1:8000/ui
4. In Security panel, set password and unlock.
5. In Storage panel, check profile and save state.
6. In Providers panel, create provider from preset, store key through Secret Vault and run metadata-only test.

Limitations: live calls disabled by default; no real patch apply; no background calls; no host project writes.
