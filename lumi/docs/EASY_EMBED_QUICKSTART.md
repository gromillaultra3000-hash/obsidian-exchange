# Easy Embed Quickstart

## REST
Start Lumi and call `/integration/handshake`, then `/resolve` or `/dialog/sessions/{id}/message`.

## Python SDK
Use `sdk/python/lumi_client`.

## JavaScript SDK
Use `sdk/javascript/src/client.js`.

## Sidecar
Run Lumi as a local sidecar process and communicate through `http://127.0.0.1:8000`.
