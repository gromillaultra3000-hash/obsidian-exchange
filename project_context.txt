================================================================================
                        OBSIDIANEXCHANGE – ПОЛНЫЙ КОНТЕКСТ ПРОЕКТА
================================================================================
ПРОЕКТ: ObsidianExchange – Telegram-обменник криптовалют без KYC
ВЕРСИЯ: Gold V23 (май 2026)
СЕРВЕР: основной (obsidian69, 185.236.228.19), белый (ggwppay, 5.206.224.157)

================================================================================
1. АРХИТЕКТУРА (КЛЮЧЕВЫЕ КОМПОНЕНТЫ)
================================================================================
- Telegram-бот (aiogram 3.x) – /root/bot/main_bot.py
- Ретранслятор (FastAPI) – /root/relay-fastapi/main.py (порт 5001)
- Старый relay (http.server, отключён) – /root/relay/app.py (порт 5000, не используется)
- Nginx – проксирует запросы на порт 5001
- База данных: SQLite (/root/exchange.db)
- Белый прокси для Platega – /root/whiteshop/relay/platega_proxy.py (порт 5003 на белом сервере)

Основные сервисы (systemd):
- exchange-bot.service (бот)
- relay-fastapi.service (FastAPI)
- support-bot.service (бот поддержки)
- polling-worker.service (фоновый опрос статусов)

================================================================================
2. ЗОЛОТЫЕ ВЕРСИИ (БЭКАПЫ)
================================================================================
Все архивы лежат в /root/bot/gold_v*.tar.gz
Последняя стабильная: Gold V23 (интерфейс в киберпанк-стиле, FastAPI, аудит-лог)
Предыдущие важные: V11, V16, V20, V21, V22

Как восстановить:
tar -xzf /root/bot/gold_vXX.tar.gz -C /tmp/
cp /tmp/gold_vXX/main_bot.py /root/bot/main_bot.py
cp /tmp/gold_vXX/relay_main.py /root/relay-fastapi/main.py
... и т.д.

================================================================================
3. БАЗА ДАННЫХ (ОСНОВНЫЕ ТАБЛИЦЫ)
================================================================================
- orders: заказы (order_id, user_id, rub_amount, crypto_address, currency, status, paid_btc_tx)
- payment_sessions: платёжные сессии (session_token, order_id, provider, status, expires_at, client_ip, user_agent)
- referrals: рефералы
- referral_addresses: адреса для бонусов
- blocked_users: заблокированные
- admin_log: логи админа
- payout_queue: очередь выплат
- provider_health: метрики провайдеров
- audit_log: аудит событий
- risk_events: события риска

================================================================================
4. КЛЮЧЕВЫЕ НЕДОДЕЛКИ И ПРОБЛЕМЫ
================================================================================
- Банки: Platega не отдаёт список банков через API; парсинг HTML не дал результата. Пока одна кнопка "Оплатить через СБП".
- Таймер/анимации: были синтаксические ошибки при вставке JavaScript в Python f-строки; решено через вынос HTML в отдельные файлы (templates/).
- Lightning Network, Monero, PWA – не реализованы.
- Docker: неудачная попытка, откатились на systemd.
- http.server заменён на FastAPI (основной relay теперь на порту 5001).

================================================================================
5. ТЕКУЩАЯ СТРУКТУРА ПАПОК
================================================================================

7. ПОСЛЕДНИЕ ВАЖНЫЕ КОМАНДЫ
================================================================================
- Проверка статуса всех сервисов:
  systemctl is-active exchange-bot.service relay-fastapi.service support-bot.service polling-worker.service nginx.service

- Просмотр логов FastAPI:
  journalctl -u relay-fastapi.service --no-pager -n 30

- Ручной запуск (для отладки):
  cd /root/relay-fastapi && python3 main.py

- Рестарт после правок:
  sudo systemctl restart relay-fastapi.service
